Online Bank Platform (Neo-Bank)

A full-stack, production-ready digital banking platform designed to simulate real-world financial systems with a strong focus on security, scalability, and clean architecture.

 Overview :

This project demonstrates the design and implementation of a modern online banking system, supporting secure financial operations, real-time market data integration, and cloud-based deployment.

 Tech Stack :
Backend: C#, .NET Core
Frontend: React
Database: SQL Server
Cloud & Deployment: Azure App Service, Azure SQL
External APIs: Finnhub, Alpha Vantage

 
 Transaction Engine :
 
Built an ACID-compliant transaction system to ensure data integrity and reliability
Supports secure peer-to-peer (P2P) transfers between accounts
Handles multi-currency wallets with accurate balance tracking
Implements partial currency exchange logic for flexible transactions
 Market Data Integration
Integrated Finnhub and Alpha Vantage APIs
Provides real-time stock and forex data
Enables dynamic financial insights within the platform

 Security:
 
Implemented multi-layered BCrypt hashing for sensitive data protection
Designed with secure authentication and data handling practices
 Cloud Architecture
Deployed using Azure App Service and Azure SQL Database
Managed environment variables securely for production
Set up CI/CD workflows for automated build and deployment

 What This Project Demonstrates:
 
Strong understanding of backend system design
Practical use of financial transaction principles (ACID)
Experience with API integration and real-time data handling
Knowledge of cloud deployment and DevOps practices
Ability to build secure and scalable applications
